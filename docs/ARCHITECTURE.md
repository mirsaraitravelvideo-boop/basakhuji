# আর্কিটেকচার — বাসাখুঁজি বাংলাদেশ

## ১. কাঠামোর ধরন

**Serverless-এর ওপর Modular Monolith।** প্রথম সংস্করণে microservices নয় — আলাদা সার্ভারের জটিলতা ও খরচ ছাড়াই একটিমাত্র সুসংগঠিত Next.js অ্যাপ চলবে Cloudflare-এর edge নেটওয়ার্কে, আর ডেটা-স্তর হিসেবে থাকবে Supabase। ব্যবহারকারী ও ট্রাফিক বাড়লে প্রয়োজন অনুযায়ী মডিউল আলাদা সার্ভিসে ভাগ করা যাবে; শুরু থেকেই মডিউল-সীমানা পরিষ্কার রাখা হবে।

## ২. মডিউল বিভাজন (A–J)

| মডিউল | দায়িত্ব |
|---|---|
| **A — Public Website** | হোমপেজ, জেলা/এলাকার পেজ, FAQ, সাহায্যকেন্দ্র, নীতিমালা পেজ, Report Listing। SEO-র জন্য প্রকাশযোগ্য বিজ্ঞাপনের আলাদা URL, sitemap, canonical। |
| **B — Property Search Engine** | জেলা/এলাকা/ভাড়া/বেডরুম/সুবিধা ফিল্টার, সাজানো, pagination। শুধু প্রকাশিত, সক্রিয় ও মেয়াদোত্তীর্ণ নয় এমন বিজ্ঞাপন। |
| **C — Property Details** | ছবির গ্যালারি, ভাড়া/অগ্রিম/জামানত, রুম-বাথরুম, সুবিধা, যাচাই ব্যাজ, সংরক্ষণ, শেয়ার, নিরাপদ যোগাযোগ, অভিযোগ। |
| **D — Landlord Portal** | নিজের বিজ্ঞাপন তৈরি/সম্পাদনা/সক্রিয়-বন্ধ, অনুমোদনের অবস্থা, খসড়া, পারফরম্যান্স পরিসংখ্যান (বাস্তব ডেটা থেকে)। |
| **E — Tenant Portal** | সংরক্ষিত বাসা, সাম্প্রতিক দেখা, সার্চ অ্যালার্ট, চ্যাট, অ্যাকাউন্ট ও গোপনীয়তা। |
| **F — Admin Control Center** | ড্যাশবোর্ড (বাস্তব পরিসংখ্যান), ব্যবহারকারী ব্যবস্থাপনা, বিজ্ঞাপন অনুমোদন/প্রত্যাখ্যান, আর্থিক মডিউলের কাঠামো (পেমেন্ট পরে)। মোবাইল-ফ্রেন্ডলি। |
| **G — Notice & Notification Center** | হোমপেজের নোটিশ বার (৫ ধরন: তথ্য/ঘোষণা/রক্ষণাবেক্ষণ/নিরাপত্তা/নীতিমালা), ইন-অ্যাপ নোটিফিকেশন, read/unread। |
| **H — Messaging** | বিজ্ঞাপন-সংশ্লিষ্ট চ্যাট, unread count, ব্লক, স্প্যাম প্রতিরোধ। কথোপকথনের সদস্যতা সার্ভার-সাইডে যাচাই। |
| **I — Maps & Location** | Leaflet + CARTO basemap, প্রতিটি বিজ্ঞাপনে lat/lng, ম্যাপ ও তালিকা ভিউ, Google Maps-এ খোলার লিংক (API ছাড়া)। GPS অনুমতি ছাড়া সংগ্রহ নয়। |
| **J — Future Tenant Management** | ভাড়া চুক্তি, মাসিক হিসাব, রসিদ, রক্ষণাবেক্ষণ অনুরোধ — বিজ্ঞাপন মডিউল থেকে আলাদা, ফেজ ৮-এ। |

## ৩. ডেটা প্রবাহ

```
ব্যবহারকারী (মোবাইল ব্রাউজার / PWA)
        |
        v
Next.js App (Cloudflare Pages + @opennextjs/cloudflare)
  - Server Components: প্রকাশ্য পেজ, SEO
  - Route Handlers / Server Actions: ফর্ম সাবমিশন, যাচাই
  - Edge Middleware: সেশন চেক, রোল-ভিত্তিক রিডাইরেক্ট
        |
        v
Supabase
  - PostgreSQL (Row Level Security সক্রিয়)
  - Auth (ইমেইল-পাসওয়ার্ড; OTP পরে)
  - Storage (অনুমতি-নিয়ন্ত্রিত ছবি)
  - Edge Functions (অনুমোদন, নোটিফিকেশন, সংবেদনশীল লজিক)
        |
        v
বাহ্যিক: CARTO টাইল CDN, Google Maps লিংক (API ছাড়া)
```

ব্রাউজার সরাসরি ডেটাবেসে কথা বলে না — প্রতিটি অনুরোধ Supabase ক্লায়েন্টের মাধ্যমে যায়, যেখানে RLS নীতি প্রয়োগ হয়।

## ৪. নিরাপত্তা মডেল (সংক্ষেপ)

1. **Deny-by-default RLS:** সব টেবিলে Row Level Security সক্রিয়; স্পষ্ট নীতি ছাড়া কোনো row পড়া/লেখা যাবে না।
2. **সার্ভার-সাইড রোল যাচাই:** admin/moderator/landlord/tenant ভূমিকা `user_roles` টেবিলে থাকে এবং Edge Function / Server Action-এ যাচাই হয়। ফ্রন্টএন্ডে বাটন লুকানোকে নিরাপত্তা ধরা হয় না।
3. **Least privilege ও মালিকানা:** বাড়িওয়ালা শুধু নিজের বিজ্ঞাপন সম্পাদনা করতে পারেন; চ্যাটের সদস্যতা সার্ভার-সাইডে যাচাই হয় (IDOR প্রতিরোধ)।
4. **গোপন কী:** service-role key কখনো ফ্রন্টএন্ড বান্ডলে যাবে না; শুধু Edge Function-এর environment-এ।
5. **ইনপুট যাচাই:** ছবির ধরন/আকার সার্ভারে যাচাই, rate limiting, XSS/SQLi/CSRF প্রতিরোধ।
6. **Audit logs:** অনুমোদন, রোল পরিবর্তন, স্থগিতকরণ — সব গুরুত্বপূর্ণ প্রশাসনিক কাজের রেকর্ড `audit_logs`-এ।
7. **HTTPS বাধ্যতামূলক**, ব্যাকআপ থেকে পুনরুদ্ধার পরীক্ষা ফেজ ৬-এ।

## ৫. জিরো-বাজেট অপারেশন নোট

- **Supabase ফ্রি সীমা:** 500MB ডেটাবেস, 1GB স্টোরেজ, মাসে 5GB egress, 50,000 MAU। **সতর্কতা:** ৭ দিন কোনো API রিকোয়েস্ট না এলে প্রজেক্ট pause হয় (প্রথম রিকোয়েস্টে ১০–৩০ সেকেন্ড দেরি)। ফ্রি প্ল্যানে নির্ভরযোগ্য ব্যাকআপ নেই — তাই **GitHub Actions দিয়ে দৈনিক স্বয়ংক্রিয় ডেটাবেস ব্যাকআপ** (ফ্রি) ফেজ ২ থেকেই বাধ্যতামূলক।
- **Cloudflare Pages ফ্রি:** unlimited ব্যান্ডউইথ ও সাইট, মাসে ৫০০ build, প্রতি সাইটে ২০,০০০ ফাইল। কার্ড লাগে না।
- **ম্যাপ:** `tile.openstreetmap.org` সরাসরি ব্যবহার নিষেধ — এটি দান-নির্ভর সার্ভার, টাইল ব্যবহার নীতিমালায় অ্যাপের ভারী ব্যবহার নিষিদ্ধ এবং লঙ্ঘনকারীদের ব্লক করা হয়। তাই **CARTO basemap CDN** (`basemaps.cartocdn.com`) ব্যবহার করা হবে — একই OpenStreetMap ডেটা, প্রোডাকশন-উপযোগী CDN, সঠিক attribution-সহ।
- **পেমেন্ট:** ফেজ ৮-এর আগে কোনো প্রকৃত অর্থ লেনদেন নয়; sandbox পরীক্ষা শুধু।
- খরচের সীমা ছুঁলে সেবা বন্ধ হতে পারে — ব্যবহার ও স্টোরেজ অ্যাডমিন ড্যাশবোর্ডে পর্যবেক্ষণ করা হবে।

## ৬. ভবিষ্যৎ সম্প্রসারণ

মডিউল-সীমানা পরিষ্কার থাকায় পরবর্তীতে যোগ করা যাবে: push notification, OTP লগইন, ইন্টারঅ্যাকটিভ Google Maps API, পেমেন্ট গেটওয়ে, ভাড়াটিয়া ব্যবস্থাপনা — পুরোনো কোড না ভেঙে।
